# YCFRP 飞牛 fnOS 应用包（fpk）

YCFRP 的飞牛版应用包，可在飞牛 fnOS 的应用中心一键安装，把 FRP 双端管理面板跑在你的 NAS 上。

## 介绍

YCFRP 是一款内置 frp 内核（frps / frpc）的 FRP 管理面板，单二进制、无外部依赖。飞牛版 fpk 把它打包成 fnOS 标准应用，安装后：

- 应用中心直接启动 / 停止 / 查看状态
- 桌面图标一键打开面板（内嵌窗口，无需记端口）
- 数据保存在应用数据目录，升级 / 卸载不丢配置
- 支持 frps 服务端 + frpc 客户端多实例、隧道管理、流量监控、中文日志诊断、多渠道通知

## 安装

1. 打开飞牛 **应用中心** → 点击右上角 **手动安装**（或「本地安装」）。
2. 选择下载好的 `YCFRP-fnos-amd64.fpk` 文件。
3. 按提示完成安装（默认安装到系统分区，也可选其他存储卷）。
4. 安装完成后，桌面会出现 **YCFRP 面板** 图标。

## 使用

- **打开面板**：点桌面「YCFRP 面板」图标，或应用中心里点 YCFRP 的「打开」。
- **面板地址**：`http://你的NAS-IP:38080`（首次登录默认账号 `admin` / `admin`）。
- **启动 / 停止**：应用中心 → YCFRP → 「启动」/「停止」按钮，或命令行 `cmd/main start|stop|status`。
- **数据目录**：配置、隧道、日志保存在应用数据目录（`/vol*/@appdata/ycfrp/var/data`），升级或卸载重装都不丢。

## 常见问题

**面板打不开？**
确认应用处于「运行中」状态（应用中心里 YCFRP 显示绿色运行中）。若启动失败，看应用中心里的日志，或 SSH 查看 `${TRIM_PKGVAR}/info.log`。

**端口被占用？**
面板固定用 `38080` 端口。如果 NAS 上已有程序占用，需先释放该端口再启动。

**忘记密码？**
SSH 进 NAS，执行：
```bash
/var/apps/ycfrp/target/ycfrp -c /var/apps/ycfrp/var/data --reset-password
```

**如何卸载？**
应用中心 → YCFRP → 卸载。默认会保留数据目录；如需彻底清除，卸载时勾选「删除数据」。

## 注意事项

- 飞牛版 fpk 是 **x86 架构**，ARM（树莓派等）设备请用 Linux 二进制包或 Docker 镜像。
- frp 内核可能被部分安全软件（如火绒）误报为 HackTool，属特征误报，YCFRP 是开源工具，可放心使用。
