YCFRP s2609.031 —— FRP 双端管理面板（Windows 版）
=================================================

内置 frp 内核 v0.71.0，免安装绿色版，双击即用。

一、文件说明
------------
  YCFRP.exe                 图形界面版，启动后弹出桌面窗口
  YCFRP-console.exe         控制台版，适合注册为系统服务或脚本调用
  启动面板.bat              双击即在后台运行面板，并自动打开浏览器
  打开面板.bat              双击即用浏览器打开面板（不重新启动程序）
  查看状态.bat              双击查看面板是否在后台运行、地址与进程号
  停止面板.bat              双击停止后台运行的面板
  README-windows.txt        本说明文件

二、快速开始
------------
  推荐：双击「启动面板.bat」，最省事的方式。

  脚本会自动在后台运行面板（关闭脚本窗口不影响运行），
  片刻后自动用默认浏览器打开面板，登录即可使用。

  也可以手动操作：

  1) 双击 YCFRP.exe 启动程序。

  2) 程序会在下列位置自动创建数据目录：

      %APPDATA%\YCFRP

     其中包含 config.json（面板配置）、tunnels.json（隧道列表）与 logs 日志目录。

  3) 浏览器访问面板：

       http://127.0.0.1:38080
       默认账号：admin / admin  （首次登录后请立即修改）

三、后台运行与启停脚本
----------------------
  四个批处理脚本都已经配好参数，双击即可，无需打开命令行：

    启动面板.bat      后台运行面板，并把浏览器指向面板
    打开面板.bat      只打开浏览器，不会重复启动程序
    查看状态.bat      显示运行状态、进程号与面板访问地址
    停止面板.bat      请求面板优雅退出，配置与流量数据会正常落盘

  说明：
    - 面板在后台运行，关掉脚本窗口、注销桌面都不会中断服务。
    - 重复双击「启动面板.bat」不会启动第二个实例，只会提示已在运行。
    - 「停止面板.bat」走的是优雅退出，等同于命令行执行 ycfrp -stop。

四、两种界面形态
----------------
  GUI 版（YCFRP.exe）
      启动后显示原生桌面窗口，可在窗口内直接查看状态，也可一键用浏览器打开面板。

  控制台版（YCFRP-console.exe）
      在命令行中运行，日志直接输出到终端，适合配合任务计划或第三方服务管理器。

      常用参数：

        YCFRP-console.exe -v                显示版本信息
        YCFRP-console.exe -h                显示全部参数
        YCFRP-console.exe -p 38080          指定面板端口
        YCFRP-console.exe -c D:\ycfrp       指定数据目录
        YCFRP-console.exe -d                后台运行（关闭终端后继续运行）
        YCFRP-console.exe -status           查看后台运行状态
        YCFRP-console.exe -stop             停止后台运行的面板
        YCFRP-console.exe -open             用默认浏览器打开面板
        YCFRP-console.exe --reset-password  重置登录账号为 admin / admin

五、默认端口
------------
  38080   管理面板（HTTP）
  7000    frps 与 frpc 通信端口
  7500    frps 内核仪表盘接口（仅本机）
  8080    HTTP 类型隧道虚拟主机
  8443    HTTPS 类型隧道虚拟主机

  首次运行时 Windows 防火墙可能弹窗询问，请勾选允许「专用网络」访问。

六、随系统启动
--------------
  方式一：把「启动面板.bat」的快捷方式放入启动目录

       Win + R 输入 shell:startup，将快捷方式粘贴进去。

  方式二：使用任务计划程序

       创建基本任务 → 触发器选择「计算机启动时」→
       操作指向 YCFRP-console.exe，参数填 -d -p 38080。

七、问题排查
------------
  面板无法访问       确认程序仍在运行、端口未被占用、防火墙已放行。
  frpc 连接失败      核对服务端地址、端口与 auth.token 是否与 frps 一致。
  端口被占用         修改隧道远程端口，或释放占用该端口的进程后重启隧道。
  忘记登录密码       运行 YCFRP-console.exe --reset-password 重置。
  提示已被占用       说明面板已在后台运行，直接双击「打开面板.bat」即可。

  面板内置中文日志与故障定位功能，可在「日志」页面直接查看成因与处理建议。
